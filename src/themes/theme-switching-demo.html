💻 Variable Reference

This entire page uses unprefixed semantic variables. Here's an example:

.button { background: var(--clr-action-primary); color: var(--clr-text-inverse); border: 2px solid var(--clr-border-strong-01); font-size: var(--type-desktop-button-default-size); } .card { background: var(--clr-bg-shade); color: var(--clr-text-default); border: 1px solid var(--clr-border-subtle); }

82 semantic variables available across:
• 52 color variables (--clr-*)
• 30 typography variables (--type-*)

🚀 How It Works

  1. Each theme file defines both prefixed and unprefixed variables
  2. Unprefixed variables reference prefixed ones: --clr-bg-default: var(--ntg-clr-bg-default)
  3. Switching themes swaps the CSS file, changing all variable references at once
  4. Components use unprefixed variables, making them theme-agnostic
